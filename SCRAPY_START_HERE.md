## 🚀 Quick Start Guide

### Fastest Path (15 minutes)

1. **Download C++ Build Tools:**
   ```
   https://aka.ms/vs/17/release/vs_BuildTools.exe
   ```

2. **Run installer (Admin):**
   - Right-click → Run as Administrator
   - Select "Desktop development with C++"
   - Click Install
   - Wait 10-15 minutes

3. **Open PowerShell and install packages:**
   ```powershell
   C:/Users/aziz/.local/bin/python3.15.exe -m pip install scrapy scrapy-playwright playwright
   ```

4. **Verify:**
   ```powershell
   C:/Users/aziz/.local/bin/python3.15.exe -c "import scrapy, playwright; print('✅ Done')"
   ```

## 🎯 What's Next After Installation

1. **Set Graph API Token**
   ```powershell

   ```

2. **Update Configuration**
   - Edit `social_media/config.py`
   - Add page IDs
   - Enable Scrapy

3. **Run Hybrid Collection**
   ```powershell
   python -m social_media.app --collect --mode hybrid
   ```

4. **Monitor Results**
   ```powershell
   cat data\extracted\posts.json
   ```
